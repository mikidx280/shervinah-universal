ACCESSIBILITY

Accessibility statement

Shervinah Universal aims to provide an inclusive experience for people with disabilities and follows recognized web accessibility practices.

Measures provided

  • Keyboard navigation and visible focus
  • Semantic headings and image descriptions
  • English and Persian direction support
  • Text enlargement, high contrast, grayscale, link highlighting, reduced motion and large cursor controls
  • Responsive layouts for desktop and mobile

Feedback

If you encounter an accessibility barrier, email shervinahuniversal@gmail.com with the page and a short description.
