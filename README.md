# Shervinah Universal — Website Prototype

A responsive bilingual (English / Persian) front-end prototype for Shervinah Universal.

## Included
- Responsive home page
- English / Persian language switch
- Full RTL support for Persian
- Brand story and destination sections
- Product catalog
- Working demo cart stored in the browser
- Newsletter interaction
- Collaboration email link
- Mobile layout

## Run locally
Open `index.html` in a browser. For best results use a simple local server, e.g.:

```bash
python -m http.server 8080
```

Then open http://localhost:8080
